## About Me

I build across web, mobile, and security tooling, whichever the problem calls for.
I write the plugins, orchestrators, and skills that put small fleets of agents to work.
I keep what I build LLM and harness agnostic, so it travels across models, frameworks, and tools instead of locking into one.
📍 Gaborone, Botswana, with a global outlook.
